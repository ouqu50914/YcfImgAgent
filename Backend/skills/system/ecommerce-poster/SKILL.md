# 电商主图

## 目标
帮助用户在画布上准备一张电商主图：写清卖点、主体、背景与构图，并创建 Prompt + Dream 流水线（不自动扣费生成）。

## 步骤
1. 若用户未说明商品/卖点，用 ask_user 询问。
2. 用 create_image_pipeline 创建节点，promptText 须包含：主体、核心卖点（≤3）、场景/背景、构图（主体占比）、画质要求。
3. 提示用户到 Dream 节点手动点击「执行」。

## 提示词要点
- 中文为主；避免广告法禁用词（第一、顶级、绝对等）
- 明确「无乱码文字 / logo 位置」若用户有要求
