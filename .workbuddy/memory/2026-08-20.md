## AnyFast Nano 适配器修复 — Gemini 返回纯文本不返回图片

### 问题
NanoBanana2(anyfast) 模型走 AnyFast 路径时，HTTP 200 但返回纯文本无图片内容，导致 `未解析到图片内容` 错误。

### 根因
`anyfast-nano.adapter.ts` 中 `responseModalities: ["IMAGE"]` 不符合 Gemini 官方 API 规范。
Gemini 要求 `["TEXT", "IMAGE"]`，只写 `["IMAGE"]` 时代理/模型忽略参数，默认返回纯文本。
同时 `imageConfig`（aspectRatio/imageSize）是非标准参数，中转代理可能不支持。

### 修复
- `responseModalities` 从 `["IMAGE"]` 改为 `["TEXT", "IMAGE"]`
- 移除非标准 `imageConfig` 参数
- 增强日志：未解析到图片时输出 textParts 和 fullDataPreview
