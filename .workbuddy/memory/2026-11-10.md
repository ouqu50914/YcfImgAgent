## 实测 GPT2.6 生图失败诊断（request_id `ig_mwau6awq_pj06fjy4`，23:19:49）
- 结论：**Ace official 模型名是有效的**（请求被 acedata.cloud 受理并返回 task_id/trace_id），失败原因是 prompt「帮我生成一个哆啦A梦的GIF图」触发内容安全策略 → `403 forbidden: The generated image was filtered by the safety policy`（≈14s）。即版权 IP 被过滤，不是模型不存在。
- 致命点在兜底：Ace 失败后回退 AnyFast，请求 `gpt-image-2.6-flare`（无 `:official`）→ `503 model_not_found: No channel configured for model gpt-image-2.6-flare under group Direct (distributor)`。已核实 AnyFast `/v1/models` 的 gpt-image 系列仅 `gpt-image-2` / `2.5-flare` / `2.5-sunburst`，**完全没有 2.6，也没有 official 变体**，所以 2.6 的 AnyFast 兜底必然失败（flare / sunburst 皆如此）。
- 误导性报错：`image.service.ts` 在第二次尝试失败时 `throw fallbackError`，只抛最后一次错误；前端 500 / toast 显示的是 AnyFast 503 的机翻中文，把首因（Ace 403 安全策略）盖住了。另 `error-toast.ts` 对已中文的文案又调了一次翻译接口，把 144 字截成 74 字「…未为模型 gpt」，toast 显示半截话。
- 待修方向：2.6 不走 AnyFast 兜底（或兜底改 Ace 另一变体）、把主渠道错误一并透出、修错误翻译的重复翻译截断。换无版权 IP 的 prompt 用 `[测] GPT2.6(ace official)` 可先验证通道本身。

## GPT Image 2.6 / 2.6 pro 原生 GIF 动图接入
- 上游文档规则：2.6 flare/sunburst（含 `:official`）支持 `output_format: "gif"`；`frame_count` 2–16 整数（默认 9）、`frame_duration_ms` 20–655350（默认 200，按 10ms 取整）；GIF 的 size 省略/auto 用 **512x512** 预设，不能套 4K；`n` 是 GIF 文件数不是帧数；按成功文件数计费（official 按 Token）；示例带 `async: true`。
- **两个隐藏阻塞点**（调研发现）：① `image.controller.ts` 是白名单式取参，前端一直传的 `size` / `outputFormat` / `moderation` 全被丢弃，后端靠 adapter 自行推导；② 两个 adapter 的 `validateAndNormalizeSize` 要求像素总数 ≥655360，而 512×512=262144 必然被拒。
- 实现策略：**不补 `size` 白名单**（避免改变现有静态图推导行为），改为 adapter 在 `outputFormat==='gif' && isGptImage26Model(model)` 时自行强制 `512x512`、跳过静态像素校验；controller 只补 `outputFormat` / `frameCount` / `frameDurationMs` 三个字段。
- 共享规则落在 `Backend/src/utils/image-format.ts`：`GPT26_GIF` 常量、`normalizeGpt26FrameCount` / `normalizeGpt26FrameDurationMs` / `buildGpt26GifParams`，Ace 与 AnyFast 两个 adapter 共用。GIF 仅 2.6 系列放行，其它模型传 gif 会被归落为 png。
- 前端 `DreamNode.vue`：仅 2.6/2.6 pro（含 4 个 `[测]` 选项）显示「图片类型」PNG/JPEG/WebP/GIF，选 GIF 显示「帧数」2–16（默认 9）+ 提示；`imageFormat`/`frameCount` 从 `props.data` 初始化并 watch 写回；GIF 时 `size=512x512`、`frameDurationMs=200`。落盘/显示链路原本就支持 .gif（image-format.ts magic bytes + `<img>`），无需改动。
- **决策与边界**：① 未发 `async: true`——项目 adapter 没有 task_id 轮询，发了会报「返回成功但未包含图片 URL」，按同步实现，需实测确认；② 对外积分仍按 10/14/18 每张（文档按成功文件数计费，不按帧数），GIF 成本更高但本次未加价；③ `headlessImageJobs.ts`（Agent/批量生图）仍固定 png，未开放 GIF；④ GIF + 参考图走 edits 时两个 adapter 也带了帧参数，但上游兼容性未验证。
- 验证：`tsc --noEmit` / `vue-tsc --noEmit` 0 错误、`npm test` **25 pass / 0 fail**（新增 3 个 GIF 回归）、三端 + qc_web 全 200、Vite HMR 无编译错误。**未做真实付费 GIF 生图**，需用超管选 `[测] GPT2.6(ace official)` + GIF 实测一次。
